# THE MIDNIGHT PLATFORM

This directory is the canonical home for the series. Story canon, reference art,
episode packages, motion clips, audio, final renders, workflows, and QC evidence
must remain below this directory.

Episode 1 is a private quality benchmark. Nothing in this series may be uploaded
or published until Episode 1 passes QC and receives explicit approval.

## Directory contract

- `series.json` — series canon and season structure
- `quality_standard.json` — fail-closed visual and audio requirements
- `assets/references/` — locked character and world references
- `episodes/epNNN/` — self-contained production package per episode
- `workflows/` — series-specific generation and validation workflows
